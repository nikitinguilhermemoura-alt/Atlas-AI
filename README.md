
# Atlas AI

Assistente virtual com interface web e backend em Python.

## Estrutura
- `backend/`: servidor e API
- `frontend/`: interface web
- `deploy/`: configuração inicial de hospedagem

## Tecnologias
- Python
- FastAPI
- OpenAI API
- HTML, CSS e JavaScript

## Segurança
Não coloque chaves de API ou senhas diretamente no código ou no GitHub.
